# Changelog

## v0.1.0 — initial MVP

- Persian RTL admin interface, using FastAPI and SQLite.
- One Iranian entry server with multiple remote nodes over separate GRE tunnels.
- FRP TCP/UDP service mappings, independent per-node tokens and start/stop/apply/status/log actions.
- Systemd installation scripts for Ubuntu/Debian.
- Initial automated tests and GitHub Actions validation.

> **Experimental release:** do not assume production reliability. Real-network interoperability and security review are still required.
